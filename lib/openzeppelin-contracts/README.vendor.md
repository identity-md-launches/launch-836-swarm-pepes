# Vendored OpenZeppelin Contracts

The unmodified ERC-20 dependency closure and MIT license are from
[OpenZeppelin Contracts v5.0.2](https://github.com/OpenZeppelin/openzeppelin-contracts/tree/dbb6104ce834628e473d2173bbc9d47f81a9eec3),
commit `dbb6104ce834628e473d2173bbc9d47f81a9eec3`.

`SHA256SUMS` records the upstream bytes. Check from this directory with
`sha256sum -c SHA256SUMS`. These are ordinary source files, with no submodule,
package manager, or network needed to build. Only the five imported Solidity
files are included. Foundry formatting excludes this upstream directory.
